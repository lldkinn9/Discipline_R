DISCIPLINE SUPPORT

日々の生活習慣・栄養バランス・エネルギー収支をミニマルに可視化するセルフモニタリングアプリ「Discipline」のサポートページです。

主な機能

  • DASHBOARD: Apple ヘルスケア（HealthKit）と連携した週間・日別カロリー収支、時刻別食事ログ、一般的な栄養基準に基づくPFCバランス、歩数の可視化
  • HABITS: 21:9 ビジュアルカードによる毎日の習慣管理・リマインド通知・4週間（28日間）ヒートマップ
  • CALENDAR: 6つの規律スタンプによる月間アーカイブと選択日の日別詳細レポート（DAY OVERVIEW）
  • AI ADVISOR (Optional / BYOK): ご自身の Gemini API Key を設定して利用できる生活習慣・栄養バランスの総合分析アドバイザー
