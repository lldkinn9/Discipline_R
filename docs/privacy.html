PRIVACY POLICY

「Discipline」（以下「本アプリ」）は、ユーザーのプライバシーおよび健康データの保護を最優先事項として設計されています。

1. Apple HealthKit（ヘルスケア）データの取り扱い

本アプリは、ユーザーの明示的な許可を得た上で、Apple HealthKit から以下のデータを読み取ります：

  • 歩数・歩行＋ランニング距離・エクササイズ時間・ワークアウト履歴（Step Count, Distance, Exercise Time, Workouts）
  • アクティブエネルギーおよび安静時消費エネルギー（Active / Basal Energy Burned）
  • 摂取エネルギーおよび主要栄養素（Dietary Energy, Protein, Fat, Carbohydrates）
  • 睡眠データ（Sleep Analysis）
  • 体重・体脂肪率・安静時心拍数（Body Mass, Body Fat Percentage, Resting Heart Rate）

これらのデータは端末内でのエネルギー収支・PFCバランスの表示、ウィジェット表示、およびユーザーが任意で実行するAIアドバイザー機能での総合分析にのみ使用されます。開発者のサーバーへ収集・保存されることは一切なく、広告目的や第三者への販売・提供に使用されることも一切ありません。

2. 習慣データおよびAPIキーの保存について

登録された習慣データおよびユーザーが任意で設定した Gemini API Key は、お使いの iOS 端末内（UserDefaults / App Group）にのみ保存されます。

AIアドバイザー機能（BYOK）をご自身のAPIキーで利用される場合のみ、当日および過去期間のヘルスケア・習慣の集計サマリーが Google Gemini API へ暗号化通信（HTTPS）を介して送信され、アドバイス文の生成に利用されます。

3. 広告表示および Pro版アップデート（App内課金）

無料版では画面下部にバナー広告が表示されます。設定画面より「Discipline Pro（¥500・買い切り）」へアップデートすることで、バナー広告を永久に非表示にすることができます。決済処理は Apple の StoreKit（App Store決済システム）を通じて安全に行われ、開発者がクレジットカード等の決済情報を直接取得・保持することはありません。

4. 医療免責事項

本アプリおよびAIアドバイザー機能は、医師や医療従事者による医学的診断・助言・治療を提供するものではありません。日々の生活習慣および栄養管理のセルフチェックを目的としています。体調に異変がある場合は必ず医師にご相談ください。
