PRIVACY POLICY

「Discipline」（以下「本アプリ」）は、ユーザーのプライバシーおよび健康データの保護を最優先事項として設計されています。

1. Apple HealthKit（ヘルスケア）データの取り扱い

本アプリは、ユーザーの明示的な許可を得た上で、Apple HealthKit から以下のデータを読み取ります：

  • 歩数（Step Count）
  • アクティブエネルギーおよび安静時消費エネルギー（Active / Basal Energy Burned）
  • 摂取エネルギーおよび主要栄養素（Dietary Energy, Protein, Fat, Carbohydrates）
  • 体重・体脂肪率（Body Mass, Body Fat Percentage）

これらのデータは端末内でのエネルギー収支・PFCバランスの表示、ウィジェット表示、およびユーザーが任意で実行するAIアドバイザー機能での振り返りにのみ使用されます。開発者のサーバーへ収集・保存されることは一切なく、広告目的や第三者への販売・提供に使用されることも一切ありません。

2. 習慣データおよびAPIキーの保存について

登録された習慣データ、目標設定値、およびユーザーが任意で設定した Gemini API Key は、お使いの iOS 端末内（UserDefaults / App Group）にのみ保存されます。

AIアドバイザー機能（BYOK）をご自身のAPIキーで利用される場合のみ、当日の集計数値が Google Gemini API へ暗号化通信（HTTPS）を介して送信され、アドバイス文の生成に利用されます。

3. 医療免責事項

本アプリおよびAIアドバイザー機能は、医師や医療従事者による医学的診断・助言・治療を提供するものではありません。日々の生活習慣および栄養管理のセルフチェックを目的としています。体調に異変がある場合は必ず医師にご相談ください。
